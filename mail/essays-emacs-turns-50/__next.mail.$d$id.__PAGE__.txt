3:T2760,<h1>EMACS turns 50</h1>
<p><a href="https://www.technologyreview.com/2026/10/20/1145399/emacs-turns-50/">原文链接</a></p>
<p>EMACS 今年满五十岁，仍被广泛使用。Simson Garfinkel 从 ENIAC 的开关和 Whirlwind 的纸带写起，回顾麻省理工学院人工智能实验室如何把 TECO 的宏收成一套人人共用的编辑命令；软件从共享变成商品之后，Richard Stallman 发起 GNU 计划，自由软件运动由此出现。</p>
<hr>
<p><img src="https://wp.technologyreview.com/wp-content/uploads/2026/09/cover-mockup-SAv_2.png?fit=19998,1958" alt="理查德·斯托曼 1981 年 EMACS 手册插图，后来的封面是一位中世纪骑士骑着牦牛"></p>
<p>理查德·斯托曼 1981 年 EMACS 手册中的插图。后来的版本，封面是一位中世纪骑士骑着牦牛。这些复杂而又带着玩心的图画，抓住了那个时代的黑客文化。</p>
<p>编程曾经和我们今天熟悉的体验大不相同。最早的程序员根本不写代码。1946 年，在宾夕法尼亚大学，为世界上最早的计算机之一 ENIAC 工作的六位女性，靠的是亲手配置开关、电缆和插接板。</p>
<p>几年之后，麻省理工学院的工程师为 Whirlwind 编程：把代码凿在纸带上，再装进计算机的内存。这使它成为最早的一批“存储程序”机器。后来，他们和其他人改用穿孔卡片，一行代码一张卡。</p>
<p>到了 1960 年代初，使用交互式计算机的程序员可以借助“行编辑器”，在电传打字机上输入代码。那是又大又吵的机器，键盘和打印机连在一起。他们一次打一行，成果存在一块旋转的硬盘上，硬盘有今天一台洗衣机那么大。可那时还没有我们现在熟悉的全屏文本编辑器，不能在显示器上同时看见并修改许多行。</p>
<p>最早的这类工具之一，EMACS，今年满五十岁，而且仍被广泛使用。</p>
<p>EMACS 于 1976 年首先在麻省理工学院人工智能实验室的早期视频终端上运行。它的核心概念如此有力，此后几十年里被反复重写，以适应许多操作系统。苹果甚至把它随 Mac OS X 一起分发。除此之外，围绕 EMACS 形成的软件共享社群，促成了今天的自由软件运动，以及 GNU/Linux 操作系统。</p>
<p>EMACS 的源头是 TECO 文本编辑器。它最初叫 “Tape Editor and Corrector”（纸带编辑与校正器），由 Dan Murphy ’65（丹·墨菲，1965 届）于 1962 年为麻省理工学院那台开创性的 PDP-1 计算机编写。程序的命令是大写字母：用户输入 I 来插入文本，输入 D 来删除一个字符，以此类推。存储介质从纸带让位于巨型共享磁盘上的文件之后，TECO 里的 T 便改指 Text（文本）。年深日久，TECO 变成了一门完整的语言，程序员可以用它创建新的命令，称为宏，用来编辑自己的代码。</p>
<p>1971 年秋，Carl Mikkelsen ’76（卡尔·米克尔森，1976 届）为 TECO 写了附加程序 Control-R，用上了带视频显示的 “glass teletype”（玻璃电传）终端。Control-R 会立刻把正在编辑的文件的改动显示在屏幕上；程序员不必再把每一行重新打印出来，才能看见变化。缺点是：显示器一次只能显示寥寥几行代码。</p>
<blockquote>
<p><strong>“经验丰富、手法老到的用户发现，EMACS 比以往任何一种编辑形式都要好用得多。”</strong></p>
<p>Bernard S. Greenberg，SM ’74（伯纳德·格林伯格，1974 年理学硕士）</p>
</blockquote>
<p>随后，在 1976 年，麻省理工学院人工智能实验室的研究员 Richard M. Stallman（理查德·斯托曼）访问斯坦福人工智能实验室时，看到一款名叫 E 的全屏编辑器。受到启发，他回到麻省理工，着手改进 Control-R。对程序底层结构最重要的改动是：每按下一个键，就运行这个键自己的宏。Control-R 因此容易定制得多。实验室的黑客们兴致勃勃地接过斯托曼的代码，开始修改并增添命令。</p>
<p>这给 Guy Steele Jr.（盖伊·斯蒂尔，SM ’77，PhD ’80）出了难题。他是实验室的研究生，经常要帮其他成员调试程序。“我注意到，如果对方用的是这些套件之一，而不是原装的 TECO，我帮忙就会困难得多，”他回忆道。“后来我想到，也许该出面斡旋，让大家就一套标准的 Control-R 命令达成共识，人人都同意使用。”</p>
<p>实验室的另一位成员 David Moon ’75（戴维·穆恩，1975 届）也来帮忙。斯托曼同样加入，并最终接手。他们一起规定了一套标准命令，用上了实验室许多早期键盘上的 Meta 键：Meta-F 把光标向前移动一个词，Meta-B 向后移动一个词，以此类推。他们把结果称为 EMACS，是 “Editor Macros”（编辑器宏）或 “Editing Macros”（编辑用宏）的缩写。“我的目标并不是造出一个了不起的新文本编辑器，”斯蒂尔说。“我是在试图解决一个社会问题。”</p>
<p>尽管如此，EMACS <em>确实</em>是一款了不起的新文本编辑器。Control-R 用起来可能很棘手；而据 Bernard S. Greenberg（SM ’74）所写的一份历史，EMACS 的用户即使“完全没有技术经验”，也能在“几分钟或一个小时内”学会编辑信件、电子邮件，甚至程序。与此同时，“经验丰富、手法老到的用户发现，EMACS 比以往任何一种编辑形式都要好用得多。”</p>
<p>斯托曼开始向任何寄给他一盘磁带、并附上贴足回邮邮资的信封的人分发 EMACS。“EMACS 不收取任何费用；你是在加入 EMACS 软件共享公社，”他在 1981 年的手册里写道。“入社的条件是：你对 EMACS 所做的任何改进，都必须寄回来。”</p>
<p><img src="https://wp.technologyreview.com/wp-content/uploads/2026/09/Screenshot-2026-08-11-at-8.43.55-AM.jpg?w=840" alt="Multics 操作系统编程手册，黑色活页夹放在桌上"></p>
<p>Multics 操作系统的编程手册。伯纳德·格林伯格在霍尼韦尔工作期间，为这套系统写了自己的 EMACS。它好到让霍尼韦尔将它商品化。</p>
<p>与此同时，格林伯格决定为 Multics 写一个自己的版本。Multics 是一套早期操作系统，那时已归他的雇主霍尼韦尔（Honeywell）所有。格林伯格的 EMACS 在 1980 年的国际霍尼韦尔软件大会上获得一等奖，霍尼韦尔开始销售它。霍尼韦尔并不是唯一把某个 EMACS 版本拿去卖的：卡内基梅隆大学毕业生 James Arthur Gosling（詹姆斯·戈斯林）后来领导了 Java 编程语言的开发，他也做了一个版本，最终作为商业产品出售。</p>
<p>从免费软件转向付费软件的这一转变，最终促使斯托曼发起一个项目：做一个可以由用户自由共享、自由改进的操作系统。他把这项工作称为 GNU 计划，以贝尔实验室越来越流行的 Unix 操作系统为蓝本。“GNU” 是 “GNU’s Not Unix”（GNU 不是 Unix）的缩写，点明它与 Unix 不同：它将是自由的。</p>
<p>该计划的第一个主要应用程序是 GNU Emacs（这时不再写成全大写的 EMACS）。GNU/Linux 操作系统那时还要再等许多年，因此，尽管计划的目标是做出一个完全自由的操作系统，GNU Emacs 最初仍运行在 Unix 上。它后来会跑在一系列操作系统上，包括 Linux，也包括其他基于 Unix 的系统。2001 年，苹果发布其基于 Unix 的操作系统的第一版 Mac OS X 时，GNU Emacs 就包含在内。</p>
<p>苹果在 2019 年停止随系统附带 GNU Emacs，但公司仍有一个名为 mg 的程序（“Micro GNU Emacs”，微型 GNU Emacs）。它支持大部分 EMACS 命令，却没有集成的编程语言，因此有人称之为 “ersatz EMACS”（仿制的 EMACS）。</p>
<p>与此同时，苹果操作系统的许多地方仍暗中支持 EMACS 命令。键盘上没有 Meta 键，但 Control-Option-B 会向后移动一个词，Control-Option-F 会向前移动一个词。</p>
