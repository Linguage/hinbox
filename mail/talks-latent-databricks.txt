<h2>Omnigent 与智能体基础设施层</h2>
<p><strong>Swyx:</strong> 在这个格局中。也许我们从 Omnigentt 开始，我们，我们，我们，我们深入聊聊。我确实认为很多人都在探索这个元 harness 概念。</p>
<p><strong>Matei Zaharia:</strong> 是啊，完全。</p>
<p><strong>Swyx:</strong> 是什么让你们走到这一步的？</p>
<p><strong>Matei Zaharia:</strong> 是的。有几条，像是，汇聚到一起的线索，我觉得这是个好迹象，说明你需要某种新东西。所以一方面，内部有所有关于编码智能体的信息。我们有非常棒的，开发基础设施团队。他们构建了一个叫 Isaac 的东西，它像是 Claude Code 和 Codex 的包装层，让你可以在网页上、在沙箱里使用它们，或者就在你的开发机器上、你的笔记本电脑上之类的。然后，他们在那里加了各种各样的东西。我们看到所有更高级的工程师，像是在用大量智能体构建自己的工作流，他们还在那之上、甚至在那之上构建自己的 UI 之类的东西。然后另一方面，像是我们自己构建智能体。我们在研究团队发布了一个叫 Genie 的数据科学智能体，那个团队由我领导。我们还为各种事情构建了很多内部智能体，然后我们还有所有面向客户的智能体。它们全都撞上了这件事，就像，“哦，我需要每隔几个月就切换模型和 harness 之类的。”再加上，如果你不能跟别人共享会话、不能有历史记录、不能有搜索，以及所有这类用于协作的上层，那这个智能体就完全没用。我从这两个情境里都思考了一下，一开始人们觉得这很奇怪。他们说，“你为什么把编码智能体和自定义智能体放在同一个东西里？”但我说，这，这是同样的问题，你只是想构建那些让你能够交付智能体的东西，如果你在意安全的话也许还能控制它，并且让它跨各种东西可移植。然后我们把一些东西做成实验原型。我们看到，是的，我们能把它做出来，然后我们就真正把它构建出来了。</p>
<p><strong>Swyx:</strong> 我在想，这个，我们姑且称之为架构</p>
<p><strong>Matei Zaharia:</strong> 是的</p>
<p><strong>Swyx:</strong> 是否映射到你们过去职业生涯中的任何东西。就像我总是会想，很多事情其实都能追溯到操作系统。</p>
<p><strong>Swyx:</strong> 很多操作</p>

<p><strong>Swyx:</strong> 系统能追溯到数据库，</p>
<p><strong>Matei Zaharia:</strong> 所以</p>

<p><strong>Matei Zaharia:</strong> 所以这件事，我确实认为它跟，像是网络协议、互联网协议有很大关系。我们还</p>
<p><strong>Swyx:</strong> 实体之间的通信。</p>
<p><strong>Matei Zaharia:</strong> 是的。我们还做过，像是数据共享之类的东西，那大概，大多数观众可能不会知道，除非他们</p>
<p><strong>Swyx:</strong> 是的，开放协议就是这个术语。</p>
<p><strong>Matei Zaharia:</strong> 是的。</p>
<p><strong>Swyx:</strong> 开放共享。开放共享。</p>
<p><strong>Matei Zaharia:</strong> 开放共享。</p>
<p><strong>Swyx:</strong> 是的。</p>
<p><strong>Matei Zaharia:</strong> 是的。所以这就像你有一家公司，你维护着某张表，比如说像 Walmart 之类的。他们有，像是库存以及每家门店卖出了什么。然后你还有供应商，他们会很乐意生产更多东西并运送出去，像是正好在你需要的那一刻。所以他们会很乐意，像是实时访问你的表。所以与其到处发邮件，或者发 Excel 表格，或者打电话，为什么你不能跟他们实时共享那张表的一个视图呢？然后他们查询，他们把它跟自己的数据连接起来，然后决定发送什么。所以这就是那种事情之一，你可能会问，比如今天既然我们可以这么快地 vibe code 任何东西，我们为什么还需要设计协议、API 或软件？你为什么不能按需 vibe code 东西呢？但对于这种互操作性，也就是多个以不同速度前进的参与方在构建东西，而你还想要某个上层来协调，你确实会想要设计它并构建它。所以这让我想起那个，像是智能体彼此对话，以及用户与智能体和工具对话。</p>
<h2>智能体云、云沙箱与保持会话存活</h2>
<p><strong>Swyx:</strong> Reynold，有没有其他评论或不同观点？</p>
<p><strong>Reynold Xin:</strong> 我觉得，顺便说一句，我们当时就到底哪一组好处会很重要有过争论，我想大概在我们决定做这件事的时候，我跟 Matei 说，“嘿，”刚好有那么一个特别的星期，我在不停地写代码</p>
<p><strong>Swyx:</strong> 从我醒来的那一刻，到我上床睡觉的那一刻，我都在，像是看着我的 Claude 会话、我的 Codex 会话。而其中一件特别烦人的事情就是不得不让我的笔记本电脑一直开着。</p>
<p><strong>Swyx:</strong> 我当时正开车去看医生，我记得，因为我想确保整个东西继续运行。</p>
<p><strong>Matei Zaharia:</strong> 但顺便说一句，听你这么说真是太让人安心了，因为我当时想，“我不知道自己是不是个小丑，我是在做这个还是像。”</p>
