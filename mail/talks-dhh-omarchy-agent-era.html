DHH：AI 为什么让我每天工作 16 小时

D
David Heinemeier Hansson
www.youtube.com2026-11-20

摘要

David Heinemeier Hansson（DHH）以前嫌 Linux 桌面离不开终端、配置难读、报错难懂。如今他做 Omarchy，却把这三样当成优点：Agent 可以跑命令、改配置，再从详细的报错里找原因。改几像素不再值得另排工期，反而让这位曾写书劝人别为工作发疯的开发者，开始每天干上 16 小时。

概述

DHH 和 a16z 的 Martin Casado、Anish Acharya 从 Rails、Basecamp 谈到 Omarchy。三人讨论了用 Agent 改桌面、给新手机平台补齐应用的可能性，也聊到代码更容易写了，为什么还有人愿意打磨最后那一点细节。后半段转向闭源模型和开放权重的竞争，以及 1990 年代的电脑文化怎样回到今天的 Linux 桌面：ASCII 屏保、用网名参与开源的人，还有明明没有实际功能、却能让人觉得电脑好玩的启动动画。

访谈正文

开场：为什么 Agent 喜欢 Linux

DHH： macOS 和 Windows 不适合 Agent 时代。过去 Linux 难用，得常常开终端，配置文件一堆，报错也看不懂。Agent 偏偏就喜欢这三样。

主持人： 能做的事情真的很惊人。

DHH： 你跟 Agent 说，「改一下我正在用的操作系统。」它真就给你改好了。谁还指望靠源代码筑起护城河，那是在做梦。明年说不定就真有超级智能了。软件可以现场变样，现在每秒 1,500 个 Token 已经做得到。要是两年后模型一秒能生成 10 万个、100 万个 Token，会是什么样？

Martin Casado： 你怎么看头部模型实验室和开源之间的关系？

从 Rails 和 Basecamp 到 Linux 桌面

Martin Casado： David，谢谢你来。我们今天聊创业、AI 和软件。大家都认识你，但还是请你简单介绍一下自己吧，从 Ruby on Rails、Basecamp、HEY 到你现在手头的项目。

DHH： 我是 David Heinemeier Hansson。我为互联网做软件差不多 30 年，其中 23 年在做 Basecamp。它是很早的在线项目管理工具，当年还不叫 SaaS。它差不多和 Facebook 同一时间上线，可见有多久了。

Ruby on Rails 就是从 Basecamp 里抽出来的。后来有人用 Rails 做 Twitter、GitHub、Shopify、Airbnb、Coinbase，还有一大堆应用。我一直在做 Basecamp 和 Rails。Basecamp 现在卖的是第五版，Rails 做到了第八版。大概五年前，我们还推出了邮件服务 HEY。这二十多年里我写了四本书，包括《重来》《远程工作》和《工作不必如此疯狂》。我也逐渐形成了自己对做公司、做技术的一些看法，现在常往 X 上发。至于我最近在干什么，我在做一个叫 Omarchy 的 Linux 发行版。我想把它做成第一个为 Agent 时代而生的操作系统。

Martin Casado： 我喜欢。

DHH： 我们做得很开心，把几十万人从 Windows 和 Mac 带到 Linux 上。大家念叨了 25 年「今年是 Linux 桌面元年」，这回说不定真能成。

Martin Casado： 你第一个 Linux 发行版用的是哪个？

DHH： 桌面的话是 Ubuntu，也就两年半前。服务器上我从 1990 年代就在用 Linux，但桌面一直是 Mac。2001 年我开始用 Mac OS X，印象里是第四个测试版，此后一直待在苹果生态里。

后来苹果越走越偏，迷上了服务带来的轻松收入，从别人的生意里抽走 30%。这买卖太好了，甚至不需要创新。你花十年造一辆卖不出去的车，推出一副卖不动的大号滑雪镜，都不耽误你从别人那里拿走 30%。倒霉的是它和开发者的关系。我替苹果说了几十年好话，最后实在受不了了，就换到了 Linux。

一句话改自己的操作系统

主持人： 这就是为什么你觉得 Linux 桌面现在有机会？这里有多少是苹果、Windows 把自己的生态搞糟了，又有多少是 AI 让你改得动操作系统？

DHH： 昨晚我还在玩这个。跟 Agent 说一句，「改一下我正在用的操作系统」，它真的改好了，实在让人惊讶。我觉得这才是 Linux 能走到更多人面前的原因。苹果待开发者不好，我当然很在意，可在意的开发者本来就没几个。很多人照样忍着，做商业软件要进 App Store，没得选。光凭这个，怎么也不至于有大批人迁到 Linux；Agent 就不一样了。

今天还有消息说，苹果要让 Agent 在 macOS 上更难用，多弹几个吓人的窗口，提醒你别让 Claude 访问文件。你不让它碰文件，那它还能干什么？

Omarchy 选了另一条路，我们把 Agent 用到底。这五六个月，整个发行版一直用 Agent 开发。我没手写过一行 Omarchy 代码，却通过 Agent 写了几十万行。我们自己能以原来想都不敢想的速度开发，也把这个能力交到了用户手上。

用户想换开始菜单、挪一下时钟、换个日历，或者给系统里的某个东西加个功能，直接开口说就行，往往几分钟以内就做好了。要是你认真体验五分钟这种什么都改得动的电脑，我觉得很难再回去。

我很看好这个想法。macOS 和 Windows 不适合 Agent，等不了多久，Agent 可能就是这类电脑最重要的东西。这 40 年来，我们的操作系统围着鼠标和点击做，给 Agent 用并不顺手。就说改 macOS 的工作区切换快捷键吧：你得进设置，一个输入框一个输入框地点，改完一个再改下一个。你也能让 Agent 模拟点击，不过那办法很笨。

Linux 以前让人头疼的东西，Agent 全都喜欢：什么事都能从命令行做，配置文件有可预测的格式，可以直接编辑，报错还把细节全写出来。这些老毛病，今年倒成了做 AI 的人买电脑时选 Linux 的理由。现在做东西的人里，还有谁不关心 Agent、不关心 AI？

我觉得苹果有可能变成 Agent 时代的 AOL：「这里有个围起来的园子，还有 Genmoji。你不用去头部实验室找真的 Agent，我们给你一个弱化过、保护得好好的版本。」可多数人要的不是 AOL，是开放的互联网。Omarchy 想给的就是那种体验。

主持人： 那手机呢？

DHH： 手机也得这么变。这就是我为什么这么兴奋。先是桌面，25 年来第一次有窗口做第三种操作系统。上次我觉得真有一个新系统能撬动全球份额，还是 2001 年的 Mac OS X。

手机能不能多一个平台

DHH： 后来窗口就关了，什么都没发生。直到今年，Linux 又有了这 25 年没见过的机会。手机也一样，一直是苹果和谷歌两家分市场，从别人做的生意里分那笔 30% 的抽成。微软也努力过，可能花了几十亿美元去做 Windows 手机，最后没做成。很大的原因是没应用，没有 Instagram 谁还会换 Windows 手机？现在这个局面正在改变，Linux 上已经看得到了。

我一直留一台 Mac，只为跑 Adobe Lightroom。我有插件，也有给相机配好的预设，不愿意扔掉。后来 Omarchy 社区有人花了大概两周重做 Lightroom。我觉得他做得还比 Adobe 的好；Adobe 做了十几年，起码花了几千万美元。想象把这事搬到手机：要是缺哪个应用，有人随手叫 Agent 写一个。那就把局面改了。

生态把人锁住，靠的是应用只能在某处用。Agent 把软件开发的价格和难度压到了几乎为零。未必得是开发者，只要能指挥 Agent，就有机会做出媲美 Adobe 这类公司的东西。竞争的起点变了。我的口号是，先拿下曼哈顿，也就是桌面；再拿下柏林，也就是手机。

主持人： 五年前，谁说要做第三个手机生态，听起来都肯定会失败。现在有一笔 Token 预算，就能重做一批最热门的应用。而且不少应用甚至不必重做，Agent 自己就能把原本交给软件的活干了。

DHH： 对。过去大家总说 Linux 成不了，因为缺 Word、Photoshop、Lightroom 之类的应用。可我上次开文字处理器是什么时候？现在我让 Agent 起草合同，自己看 Markdown，满意了就让它输出一份漂亮的 PDF。

最近我在筹办 Omacom 基金会，就是 Omarchy 背后的非营利机构。我们筹到的 Token 和捐款大概值 2,300 万美元，要做很多份合同。全是 Agent 做的，没用过文字处理器。我过目之后，让它把我的签名放上去，再发出去。我已经不需要 Word 了。

照片也一样。你想把照片弄好看，难道要花数十乃至上百小时学 Photoshop？多数人会让 Agent 改。比如把左边那个家伙去掉，只留下这两个人。就这么一下。过去像 Photoshop 这样的软件背后是一门手艺，有人得学好几年。现在 Agent 能不用打开那个应用就做一部分活。就算你确实想要某种功能，我在 Emacs 社区已经看到，人们需要 Word 或 Photoshop 哪个功能，就随用随做。

眼下还是早期，生成速度一秒大概 50 个 Token，开超快模式也就 120 个，还不够像在现场做东西。Fireworks 两周前在大会上演示了每秒 1,500 个 Token。现场问它能不能做个俄罗斯方块，四秒钟后游戏就跑起来了。接着做个横版射击游戏，画面已经跑着了，又说加激光、加炸弹、怪兽再大点，游戏就跟着变。未来的软件可能就是这样，当场改，当场跑。

如果两年后速度成了每秒 10 万、100 万个 Token 呢？新生态以前那些门槛会少很多，连搭生态本身都容易了。我和主要搭档 Ryan Hughes 兼职做了两个半月，做出 Omarchy 现在这个走红的版本。我们两个人，对上微软几千个程序员、各家大公司几万个人，竟然能做出我们觉得更好的东西，这过去根本没戏。

过去二十年，风投把钱花在招开发者上，因为光做出东西就需要组团队，再备上几年的钱。现在时间压到了几天、几周，最慢也就是几个月，靠的还是眼下的模型。我开始做 Omarchy 这一阶段时，用的还是 Opus 4.8。后来有了 Sol，现在有 Opus 5.5，从 4.8 到 5.5 差得太远了。圣诞节前也许还会有新模型，就算没有，明年年初也会有。换代越来越快，谁还以为靠几百万行现成源代码就护得住自己的生态，那是在做梦。

写代码快了，最后的 2% 还得打磨

Martin Casado： 听你这么说挺有意思。我一直觉得你是个手艺人，审美好，做出来的东西用着也特别顺手。我 50 岁了，还在打《星际争霸》。最近一次补丁，他们改了幽灵特工的数值。这个兵种出来都 20 年了，人家还在微调。我知道，找大语言模型写个东西可以很快。但不论看你的软件还是看《星际争霸》，做到最后，软件就是这些和代码行数没多少关系的微调。那一长串设计决定，才像护城河。是不是有些东西其实没变？你还是需要有人爱软件，愿意把自己的东西放进去，只是不用亲手写那几行代码了。

DHH： 完全是这样。现在我能把更多审美、想法和完美主义放进软件。看见哪儿不对劲，哪怕差几个像素，想改到动手之间几乎没有阻力。任何一处不够好，都能接着磨。这就是我现在每天工作 16 小时的原因。

我还专门写过一本书，叫《工作不必如此疯狂》。可我现在工作确实够疯狂的。你要是像我这样事事想做到完美，喜欢一点点把东西磨好，这些工具就像突然给了你超能力。那感觉很上瘾，对健康和睡眠甚至有点危险，至少眼下一阵子是这样。

任何人都能做，不代表所有人都会去做。还是得有个想法，还要在意做出来是什么样，能把零件拼到一起，再咬牙把它做完。不少项目一开始看着很有希望，做着做着就没兴趣了。对很多人来说，最开心的是完成前 80%。后 20% 东西还不顺，有些 Bug，热情也没了。我偏偏在最后 2% 才最有劲。头 98% 我没那么在乎，我就想做最后这点。做软件的满足感，我全在这里找。

你要是这种人，喜欢一直往下做，直到东西真的像样，现在就特别容易上瘾。至少现在还是要有人来带这些 Agent。我没找到一种设置，只说一句话，设计到成品就都完美。眼下还得有人的眼光。

有这种眼光，又感觉自己带了一整支队伍，还不用付协调成本。以前我就说过，37signals 大约 60 人，我不想换成一家 6,000 人甚至 60,000 人的公司。是能做更多，但让我管 60,000 人？那也太折磨了。可要是通过 Agent 获得相当于那么多人的产能，我就有兴趣了。不用扯皮，没有人事，没有委员会，只剩我和一群 Agent，用很快的速度做我想象中的那台好电脑。

Shopify 的 Tobi Lütke 在周末这么干，到了办公室，又要管一家实打实的 7,000 人公司。他说那感觉就像从超空间飞行里退出来。就你和 Agent 时，飞得好好的。一进办公室，唰一下停住，得管人事、各个团队、进度、报告和经营公司带来的各种杂事。现在你可以换个做法，少掉那些事，还能拿到差不多甚至更好的结果。

更夸张的是没花多少钱。差不多一个月前我在 X 上开玩笑，说我 Token 管够。我干了 20 年，现在买得起想买的量。可你知道我实际买了多少？三个 Claude 订阅。过去三个月，我想得起来大概有两周额度用完了，或者快用完。大多数星期，一份 200 美元、20 倍额度的订阅，就够我把要做的事做完了。这并不只是有无限预算的人才能玩的，而我们说的还是最前沿的模型。

我还没算开放权重模型、更便宜的模型、本地跑模型，或者各种优化。我就是打开 Opus 5.5，让它去修。现在反倒是我已经没法同时推进更多事了，而且手头的事走得飞快。

所以我觉得现在还有人的位置。但我也没自负到觉得它会永远在。也许明年真有超级智能，样样都比人强，连打磨一台完美的电脑都做得比我好。到时你说一句「给我做台很棒的电脑」，它唰唰唰，连 Linux 内核和其他东西都给你定制好了。我现在正享受这一刻：人还能多做一点，同时手里又有这么大的能力。也许只有一眨眼。谁知道呢，也许明年年底我们全完了。先享受现在吧。

什么算超级智能

Martin Casado： 我得问问，你有没有自己的超级智能测试？我举个例子。每次有新模型，我就让它去买让自己有个实体所需的东西。我家一直有机器人零件送来，真不是开玩笑。我给它 2 万美元预算，让它自己去造机器人。然后就有 OLED 显示屏之类的东西陆续寄到。它离真的做到还远，但我的测试就是这样：等它自己订零件，造出一台能走、能自主行动的机器人，我就知道到了。你有类似的标准吗？

DHH： 没有。我也许该有一个。但就软件开发而言，我的感觉是，我们已经有超级智能了。把能力覆盖的范围算进去，AI 比我认识的任何程序员都强。在很窄的领域，个别厉害的程序员还能胜过 Agent。但把所有事放到一起，再算上它做事的速度，我觉得这已经算了。我只要给提示，加上一点引导，就能做出我想做的软件。

你说机器人倒挺有意思。我大概两周前刚去中国，看了宇树科技，也去了另一家。宇树那边的看法跟硅谷不太一样。我刚看过 Dwarkesh 的访谈，有人说明年可能就有超级智能，还会迅速起飞。宇树的人说，不知道，四年、五年，也许十年吧。做软件的人觉得迫在眉睫；做执行器和机械的人说，你让机器剥个洋葱都挺难的。

Martin Casado： 现在我的 Grokbot 觉得，给我家安排一个 AI，最好的办法是做智能家居，所以它老是给我订智能家居的东西。我家大概会先出现《星际迷航》那样一张挂在墙上的屏，上头有张脸跟你说话，能控制家里的设备，还不是那台真机器人。

DHH： 倒是挺务实的。

Martin Casado： 这可是它决定的，不是我决定的。

DHH： 不留神就是这么变成回形针的。目标给得含含糊糊，什么「最大化人类幸福」，啪一下，你就成了原材料。

主持人： Martin 大概得在这里打个备注。David，你刚才提到开源。你一直敢唱反调，对权力集中也有自己很强的看法。你怎么看头部模型实验室和开源之间的关系？

头部实验室与开放权重

DHH： 我们一定得有开源和开放权重，两边才能有竞争，大家才不至于乱来。我职业生涯里已经有两次，看着两家公司把市场全分了，心里很不是滋味。大概 2000 到 2009 年，互联网短暂给过我们一个避风港。那时最重要的平台完全开放，不收费，谁想做什么就做什么，不用求人批准。后来手机平台崛起，好日子结束了。突然，你又得求别人允许你的应用上架，实际上是在求人允许你的生意存在。

我受不了这一点。我很欣赏 OpenAI 的 5.5，也欣赏他们做的事。但要是最后就两家公司说了算，尤其是政府拿强制力给两家公司兜底，那就是噩梦。行业在 1990 年代经历过类似的事，围绕加密技术争过一场。当时差点禁止公钥加密，因为美国国家安全局等机构问：「那我们以后怎么监听？」

想想没有加密技术的互联网会怎么发展。怎么做生意？怎么通信？全球经济、许多行业和 Web 本身都会因此受损。我觉得 AI 现在也到了类似的关口。我常听见聪明人说，也许干脆该让政府接管。哪怕政府不接管，只让两家实验室把商业市场分完，也够糟了。我们得避免走到那一步。

好在闭源模型的竞争，比我见过的电脑行业其他阶段都激烈。领跑的两家之外，SpaceX 的 AI 也追得很近。谷歌呢，有时还在牌桌上，有时又像跑到哪个岛上抽点奇怪的东西去了。至少它有潜力，另外几家实验室也正一点点追上来。

更要紧的是，开放权重模型也在变好。究竟落后多久不好量化。GLM-5.3 或 DeepSeek Flash 这类，可能差六七个月，有的任务甚至没那么久。现在各种基准评测不少，有人发个榜，说自己和 Opus 4.8 一样好。我试过就会想，你的评测里也许一样好，真干活就不是一回事。

可那又怎样？它们已经能派上用场，还能在自己的机器上跑。大概半年前我写过一篇文章，说买快一点的个人电脑没有意义，当时那些能在本地跑的模型太弱，做不了什么要紧的事。幸好我说错了。同一年还没过完，一台 DGX Spark 就能跑真能用的模型。Qwen3.8-Flash-Next 就完全能用。几千美元买个能放上桌的盒子，里头就有能用的智能。这太了不起了，我们很需要它。

但两边我都想要。开源社区有些人态度很硬，觉得不开源就免谈。我不这么想。我也为美国那两家领跑的实验室高兴，因为它们的成果我们能用来做东西。只要有人与它们竞争，它们就不能随便把 Token 涨到一百万个 500 美元，然后坐着收钱。要真涨到那儿，我们还是会付的。社交媒体和 Web 发展起来时，这事就演过一遍：谷歌和 Meta 分市场，只要每花一美元有机会多收回一分钱，投广告的人就愿意继续投。按我的说法，那两家公司拿走了在线广告价值链里 99% 的价值。它们有些贡献我也承认，可做到最后把价值几乎都收走，我觉得挺可怕。

不管换哪家公司，不受约束都会这么做。资本主义就是这么运转的。许多时候我甚至觉得这是它的长处，正因为有人想做出下一个谷歌、Meta、Anthropic 或 OpenAI，或者想持有它们的股票，投资才会进来。你可以同时这么想：为最前沿的进展高兴，也坚持要有开放权重。几条路都走得通，我们才有机会走到那个资源充足、人人都能过得好的局面。

Omarchy 能不能超过 macOS

主持人： 模型越能干，我们就越敢想。就连那些做软件做完前 10% 就最开心的人，现在也得把目标抬高一点才能过瘾。五年前算魔法的东西，今天做出来可能还嫌差。我做个能现场改自己的游戏，有那么多功能，发条帖，结果才 40 个赞。我这是在干吗？现在你在推动一轮 Linux 桌面革新。再往上一步，接下来一两年里，有什么是你以前想都不敢想、现在却可能做出来的？

DHH： Omarchy 的目标确实越抬越高。我去年才开始做，最初真的是手写的。十个笨手指敲点 Bash 脚本，骂 Bash 骂了不少，能干的也有限。那时只想给自己做台更舒服的电脑，找个不由苹果决定我能干什么的地方。我自己用，五个朋友用，网上再有几个人用，就挺好了。

后来真做了出来，还有几万人用。一个不错的小开源项目，我也有了更好的电脑。然后 Agent 来了，我一下子从「做台稍好一点的电脑」变成「天哪，我可以做出一台完美的电脑」。我用了 40 年电脑，这 40 年里想它能做的事，现在差不多一个人就能把它们做出来。不过和朋友一起更好玩，所以我也邀请了几十万人一起来。

看到这件事不光可能、还真在发生，看到人们用上 Linux，觉得它比 macOS、比 Windows 好用多了，那太有满足感了。人当然会有点膨胀。我现在的妄想是，咱们说三年吧，我们能做得比 macOS 大。

在我看来，全球也就 1.8 亿 macOS 用户。在美国看起来很多，尤其是在硅谷走一圈，人人都用 Mac，可放到全球看就不算多。1.8 亿，连个三流互联网服务都算不上，大平台可是几十亿用户。Linux 怎么就不能超过它？听起来像妄想，是因为 Linux 圈说要拿下桌面已经说了 25 年。可现在突然加速了，事情真在发生。

最近四五个月，甚至没到那么久，我的目标一直在变。最新的 Quattro 版，开发时全力用 Agent，做出来也把 Agent 交给每个用户。看到几十万人来用，我就开始想，也许三年都是妄想，可要不要 12 个月后回来看看？有没有可能一年内把 Mac 挤下去？

苹果花了二十来年给 macOS 建起现在这个位置，往前说还是一家从 1970 年代一路走过来的公司。但我真觉得有可能。接下来一年我不会押超过一半的概率，也不会把它排除。既然实验室有些聪明人都觉得，再给一年，递归自我改进就能给我们弄出一个 AI 超级大神，那我们把排名第二的操作系统挤下去，总还说得过去吧。

这只是我在自己这块地方的野心。我不太擅长把野心铺得很大。让 Elon 那样的人去想「我们要在所有行星上定居」好了。听着很棒，去火星的星舰上给我留个座，我当然愿意去。不过那不是我。我想在很窄的范围里尽可能有野心，把力气全投进去，也尽量不去想 12 个月之后，因为我觉得越这么想，越容易让 AI 把自己想魔怔了。

我喜欢的是 AI 带来的兴奋感。比较轻，只要对未来高兴、乐观，把注意力放在手头工具能做什么、眼下在造什么。硬要往前想两三四代模型，人就容易发疯。到时还有谁的事？人为什么还非活着不可？我们都会变成回形针吗？

我觉得这样想下去不好。我看不少做 AI 安全的人，整天都在想：未来 12 个月所有最坏的事一起发生，那不是很糟吗？当然会很糟。想象你 1944 年坐在奥本海默旁边，说这东西一出来，五年后就会遍地核废料，整个地球寸草不生。实际怎样？要我说，原子弹反倒是有利于世界和平的一件大事。后来有长达 50 年的冷战，至少没发展到核毁灭。未来很难预测，我尽量不做这种预测。

我喜欢威廉·吉布森那句话：未来已经到来，只是分布得不均匀。自己用这套系统时，我已经看到了一些未来，对这些我倒敢作点预测。要是人人都能做我现在做的事，也看得到这些可能性，GDP 年增速到 3%、4%、5% 甚至 10%，我觉得都不出奇。可一年后的模型是什么样？那就再摇摇占卜球，重新问一次吧。

跟谁学，怎么理解反 AI 的情绪

Martin Casado： David，刚才 Anish 和我还在聊，AI 浪潮有个意外的好处：好多我们年轻时敬仰的人都回来了，还在帮大家找方向。现在有很多困惑和害怕。你在，Eric Raymond 回来了，还有 John Carmack，都是过去 30 年响当当的人。先谢谢你做的这些。我看你讲「软件时代结束了，现在我们是建造者」，当时一个人听着，都忍不住说对。你是在带一代人走过这段混乱时期。那你自己做这些事时看谁？谁看得准，值得关注？不是每个人都亲历了互联网、大衰退、移动互联网和共享经济那几轮变化，你自己的参照也能帮到别人。

DHH： 有意思的是，我真心佩服编程本领的人，百分之百都已经扎进来了。也不奇怪。凡是吃过苦、用老办法做成过点东西的人，很难否认这些工具能把手上的活做得更快。有些人大概因为已经很成功，并不觉得受威胁。可还有一大块处境很尴尬，我也不说是谁的错，事实就是这样。

大多数程序员没富裕到可以不工作。职业走到这一步，觉得是靠多年辛苦、学了一堆东西才挣来的，现在却突然担心：明天这些还值钱吗？要是大家都不是程序员了，都叫「做东西的人」，我真擅长做东西吗？我自己也不知道。

我觉得应该理解那份焦虑，就像应该理解 1970 年代底特律的汽车工人，或者英国那些最早的卢德派织工。一个行业怎么变，身在里头的人感受最深。可理解他们，不等于我要回工业化以前，牵头牛拿把锄头种地糊口。我也不想回到底特律工人靠每天在流水线手工装配过上体面日子的时代。我觉得不用往回走。我们该往前走，想个办法让大家一起跟上来。这事也跟情绪有关，现在也确实在打情绪仗。

有人是为自己的前途焦虑，那很真实；也有人发现了一个听众群，决定专门扮演反 AI 的那个人。这样的人不止一个，到处都是，还有整个社群迷上了这一套。我开个刻薄的玩笑：你把最招人烦的蓝头发「觉醒派」和反 AI 的人各画一个圈，画出来就会是同一个圈。某种程度上，还是上回那一仗，或者说每一仗，因为阵营的界线就这样画好了。

照我看，他们碰巧遇到了这么个局面：最不喜欢的人先拥抱了 AI，那他们自己好像就只剩下反对了。我倒觉得这有点反讽。大约五年前，他们看上去掌握了所有文化话语权，随时能让任何人消失，那时我也对未来挺焦虑。现在情形变了一点吧。但各方也没变干净。别掉进逢事只分阵营的坑，更别以为对 AI 不舒服的人都是什么蓝头发的傻子。我说的是反过来：我嘴里那些蓝头发的傻子，都反 AI。

还是得想想怎么让他们跟上来。你可以对这件事有任何感受，可要往前就只能穿过去，不会倒退。没人会心甘情愿丢掉这项技术，除非都变成 AI 仓库里成堆的回形针。它已经到这里了，世界已经变了，以前也有过很多次。莱特兄弟飞起来以后，世界就不一样了，不会什么还都靠船运。我们该主动往前走。

至于我看谁，先是同路人。你说的 Carmack，还有 Tim Sweeney、Mitchell Hashimoto，我很佩服的人多得很。我整个职业生涯，一直在用这些人参与做的软件。他们全都在拥抱这轮变化。再一个就是 Linux 和 AI 圈里都出现了一个有趣的现象：用化名的黑客又回来了。

用网名做东西的人回来了

DHH： 安全圈一直有这种人，现在这种风气到了更主流的地方。Omarchy 核心团队和 Omacom 基金会的成员里，有人就用化名。比如 outfoxxed，他做了 Quickshell，我们用它来做桌面交互；还有一位做美术的 Hankore。一下把我拉回了 1990 年代，电话黑客、只向小圈子开放的留言板，我特别喜欢那股劲儿。

电脑又有了当年的活力。1980、1990 年代，最前沿站着的还是黑客和喜欢试东西的人。互联网有过那么一小段时间也是这样，接着商业化了，被平台接管，有了社交媒体，那股劲儿也就没了。本地 AI 圈现在倒有不少这样的人。比如 Omacom 基金会资助的 0xSero，还有 Mia’s Lab。他们用的都是化名；0xSero 的身份好像有人知道，但他还是用网名。

我喜欢这股劲头。AI 让一个人也能在行业往前走的时候出力。以前互联网一商业化，许多前沿工作就被大公司包揽了。谷歌做 Chrome，仿佛全城就这一个浏览器。再从头做一个几乎不可能。我觉得，除了 Linux 内核，浏览器引擎差不多就是人类做过的最复杂的软件。电脑上那些要紧的地方，一块一块被封起来，只有最大的公司做得动。现在又能让更多人参与了，能还给黑客，也能让一个人做出点有分量的东西。所以现在我看到谁用化名在网上做了件有意思的事，就很想关注一下：这边有好东西。

主持人： 我喜欢。就是反 LinkedIn 文化，跟 LinkedIn 完全反着来。

DHH： 这离不开 X。它把艺术家、用化名的黑客、本地 AI 圈都连在了一起。如果 Elon 买下它之前，还是我说的那帮人管着它，也许根本不会有这一切，大家都只能看一堆 LinkedIn 式的废话。

把 1990 年代的 Demo 做进桌面

Martin Casado： 对了，再说一个我特别喜欢的东西。还记得 1990 年代的 Demo 文化吗？

DHH： 天哪，当然记得。

Martin Casado： 它在 AI 的创作圈里又回来了。有些最精巧的 Demo 是网上几个没什么名气的艺术家做的。他们根本不想创业，就是喜欢做。我都想不起上回有这么一股劲儿是什么时候了。

DHH： 我想把这些全做进 Omarchy。不知道你试过没有，里头有个很有辨识度的屏保，就是 ASCII 字符画，轮着展示 40 种 Demo 特效。看上去像是从 1995 年哪场 Demo 聚会的开场里直接拿出来的。我们一边把效果做进来，一边保留终端的样子。它和 macOS、Windows 的审美都不一样。过去不少 Linux 发行版觉得，做个终端版 Windows，大家就会喜欢。可谁想要本来就没多好的东西的廉价仿品？人想要有自己样子的东西。Omarchy 就是 1990 年代 Demo 圈那股味儿。

我就是要做出这种感觉。这场连线开始前，我还在弄一项让用户在自己机器上跑 AI 的功能。本地模型启动要等一会儿，可能几秒，有时几分钟。我就趁加载时又塞了一个 ASCII 特效，一些很酷的字符在屏幕上飘。它有什么实际功能吗？一点都没有。就让你觉得：我这台电脑真酷。

1990 年代的 Demo 文化给我的就是这种感觉。我那时也玩盗版游戏，启动时会先跳出一段开场，写着「Razor 1911 破解」之类，字在屏幕上转来转去。我每看到一次，都觉得自己当天也酷了一点。

主持人： 那时的 BBS 文化也有这股味儿。哪怕你一天到晚只是在 Excel 里挪表格，Macintosh 启动那一小会儿，至少能让你觉得自己活过来了。还记得那些协议吗？XMODEM、YMODEM、ZMODEM、Kermit。为什么叫 Kermit？不知道，但听着就很酷。

DHH： 我 14 岁就在卧室里开过一个只向小圈子开放的 BBS，接了三条电话线。丹麦那家垄断电信业务的公司派人来装第三条线，看到这儿就一个 14 岁的小孩，大概在想，这什么情况，肯定不合法。他猜对了，确实不合法，也确实酷。我现在还记得 USRobotics 调制解调器以 33.6 kbps 接通时的声音。

这声音太有辨识度了。我希望电脑多一点这样的东西。电脑该有一点神秘感，够酷，也不用磨到一点棱角都不剩。我很喜欢苹果，但我觉得 Jony Ive 把铝壳抛得太光滑，顺手也把电脑的个性给磨光了。也许那套东西在一段时间里很好，但那段时间结束了。黑客们要回来了。

Martin Casado： David，真的很感谢你现在做的事，也感谢以前做的这些。谢谢你来，我们聊得很开心。

另一位主持人： 谢谢你，David。

DHH： 聊 1990 年代的 Demo 文化、黑客，还有这些好玩的东西，总是很开心。以后咱们再一起做点什么。

主持人： 下次当面聊。顺便问一句，你发的那张办公室照片，外面的漂亮景色是真的吗？

DHH： 当然是真的。我现在不在那间办公室，不然就给你转一下镜头了。那间办公室在马里布。我怎么看都不腻，所以老发那张图，发给自己高兴的。我还是不敢相信自己能在那儿工作。资本主义的一点战利品吧。想想看，这间办公室是商业软件挣来的。

主持人： 真谢谢你抽时间。

DHH： 谢谢你们请我。下次见面聊。

主持人： 没问题。保重，再见。继续玩电脑，玩得开心。
