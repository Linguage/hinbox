11:T3a13,<h1>怀特塞兹研究组：撰写论文</h1>
<h2>摘要</h2>
<p>本文是哈佛大学化学家怀特塞兹撰写的经典学术写作指南，系统阐述了科学论文的本质、提纲驱动的写作方法以及写作风格要点。文章强调论文不仅是研究成果的归档工具，更是规划和组织研究的框架，主张从项目早期就开始围绕数据构建提纲，并通过反复迭代修改来高效完成论文写作。</p>
<h2>核心概念及解读</h2>
<p><strong>提纲驱动写作法</strong>：指在动笔撰写正文之前，先围绕数据、图表和组织结构反复打磨提纲，待框架确定后再填充文本，从而大幅提升写作效率</p>
<p><strong>假说检验导向</strong>：科学研究的核心目标不是收集数据，而是提出假说、通过实验检验假说、得出结论并传播给他人</p>
<p><strong>数据优先于文本</strong>：论文应被视为实验结果的有序集合，信息尽可能通过图、表、方程式和反应路线呈现，文本仅作辅助说明</p>
<p><strong>重要性排序原则</strong>：论文内容应按结果的重要程度而非实验的时间顺序组织，最重要的发现放在最前面，次要内容后置或省略</p>
<p><strong>迭代式提纲修改</strong>：提纲需经过导师与学生之间多轮交换审阅和修改（通常四到五次），期间常伴随补充实验，最终使数据和结构趋于完善</p>
<ul>
<li>作者：乔治·M·怀特塞兹（George M. Whitesides）</li>
<li>原文链接：<a href="https://intra.ece.ucr.edu/~rlake/Whitesides_writing_res_paper.pdf">Whitesides' Group: Writing a Paper</a></li>
</ul>
<h1><strong>1. 什么是科学论文？</strong></h1>
<p>一篇论文是对假说、数据和结论的有组织的描述，旨在指导读者。论文是研究的核心部分。如果你的研究不能产出论文，那还不如不做。“有趣但未发表”等同于“不存在”。</p>
<p>要认识到，你做研究的目标是提出并检验假说，从这些检验中得出结论，并将这些结论传授给他人。你的目标不是“收集数据”。</p>
<p>一篇论文不仅仅是存档已完成研究项目的工具；它也是规划进行中研究的框架。如果你清楚地理解论文的目的和形式，它将在组织和进行研究方面对你大有裨益。一份好的论文提纲也是一份好的研究计划。你应该在整个研究过程中不断撰写和修改这些计划/提纲。开始时，你可能更多的是计划；结束时，则更多的是提纲。在纸上不断努力理解、分析、总结和重新阐述假说，将比那种收集完所有数据后才开始整理的过程对你来说效率高得多。</p>
<h1><strong>2. 提纲</strong></h1>
<h2><strong>2.1. 撰写提纲的理由</strong></h2>
<p>我强调提纲在撰写论文、准备研讨会报告和规划研究中的核心地位。我尤其相信，对你我而言，从提纲开始写论文是最高效的方式。提纲是一份书面计划，包含了论文的组织结构以及其所依据的数据。事实上，你应该将提纲视为一套精心组织和呈现的数据集，附带有相应的目标、假说和结论，而不仅仅是文本的提纲。</p>
<p>提纲本身包含的文本很少。如果你我能在提纲的细节上达成一致（即在数据和组织结构上），那么支撑的文本就可以相当容易地组合起来。如果我们对提纲无法达成一致，任何文本都是无用的。撰写论文的大部分时间花在文本上；而大部分的思考则投入到数据的组织和分析中。在开始撰写文本之前，经历几轮（甚至多轮）提纲修改，在时间上相对高效；而撰写论文全文的多个版本则非常缓慢。</p>
<p>我所有的写作——论文、报告、项目申请书（当然，还有研讨会的幻灯片）——都从提纲开始。我强烈建议你也学会如何使用它们。</p>
<h2><strong>2.2. 你应该如何构建提纲？</strong></h2>
<p>经典方法是从一张白纸开始，不按顺序地写下你所有关于这篇论文的重要想法。问自己一些显而易见的问题：</p>
<ul>
<li>“我为什么做这项工作？”</li>
<li>“它意味着什么？”</li>
<li>“我打算检验哪些假说？”</li>
<li>“我实际检验了哪些？”</li>
<li>“结果是什么？这项工作是否产生了一种新方法或新化合物？是什么？”</li>
<li>“我做了哪些测量？”</li>
<li>“哪些化合物？它们是如何表征的？”</li>
</ul>
<p>勾画出可能的方程式、图表和反应路线（schemes）。关键是要抓住主要思想。如果你开始研究是为了检验一个假说，但在看到已有结果后，觉得数据似乎更适合检验另一个假说，别担心。把它们都写下来，然后挑选假说、目标和数据的最佳组合。论文完成时的目标常常不同于开始工作时的理由。很多好的科学研究是机会主义和修正主义的。</p>
<p>当你写完能想到的所有内容后，另拿一张纸，尝试整理第一张纸上的杂乱内容。将你所有的想法归入三个主要部分（1-3）：</p>
<ol>
<li><strong>引言 (Introduction)</strong>
<ul>
<li>我为什么做这项工作？</li>
<li>核心动机和假说是什么？</li>
</ul>
</li>
<li><strong>结果与讨论 (Results and Discussion)</strong>
<ul>
<li>结果是什么？</li>
<li>化合物是如何合成与表征的？</li>
<li>测量了什么？</li>
</ul>
</li>
<li><strong>结论 (Conclusions)</strong>
<ul>
<li>这一切意味着什么？</li>
<li>哪些假说被证实或证伪了？</li>
<li>我学到了什么？</li>
<li>为什么这项工作有意义？</li>
</ul>
</li>
</ol>
<p>接下来，对每个部分进行更细致的组织。专注于组织数据。构建图、表和反应路线（schemes），以尽可能清晰和简洁地呈现数据。这个过程可能很慢——我可能会以不同方式勾画一个图五到十次，试图决定哪种方式最清晰（并且看起来最美观）。</p>
<p>最后，把所有东西——各部分的提纲、表格、图表的草图、方程式——都整理好。</p>
<p>当你满意地认为已经包含了所有数据（或者知道你打算收集哪些额外数据），并且有了一个合理的组织结构时，把提纲交给我。只需指出缺失数据将放在哪里，你认为（假设）它们会是什么样子，以及如果你的假说正确你将如何解释它们。我会审阅这份提纲，加入我的意见，提出修改建议，然后返还给你。通常需要四到五次迭代（常常伴随着额外的实验）才能就提纲达成一致。当我们达成一致时，数据通常已经处于（或接近）最终形式（也就是说，提纲中的表格、图表等将成为论文中的表格、图表……）。</p>
<p>然后你就可以开始写作了，并且可以确信你的大部分文字会被采用。</p>
<p>高效利用你我时间的关键在于，我们尽早在一个项目开始时就交换提纲和草案。<strong>无论如何，不要等到数据收集“完成”才开始写提纲。</strong> 没有哪个项目是真正“完成”的，一旦你看到一个项目的基本结构，就尽快提出一个合理的论文框架和提纲，这样可以节省巨大的精力和大量时间。即使我们决定在认真组织论文之前还要做大量额外工作，撰写提纲的努力也已经有助于指导研究方向了。</p>
<h2><strong>2.3. 提纲内容</strong></h2>
<p>一份提纲应包含：</p>
<ol>
<li><strong>标题 (Title)</strong></li>
<li><strong>作者 (Authors)</strong></li>
<li><strong>摘要 (Abstract)</strong>
<ul>
<li>暂时不要写摘要。这可以在论文完成时再做。</li>
</ul>
</li>
<li><strong>引言 (Introduction)</strong>
<ul>
<li>开头一两段应完整写出。特别注意开篇句。理想情况下，它应简明扼要地陈述工作目标，并指出为何此目标重要。</li>
<li>总的来说，引言应包含以下要素：
<ul>
<li>工作的目标。</li>
<li>目标的理由：为什么这项工作重要？</li>
<li>背景：其他人做了什么？如何做的？我们之前做了什么？</li>
<li>读者指南：读者在论文中应关注什么？有趣的亮点是什么？我们采用了什么策略？</li>
<li>总结/结论：读者应期待得到什么结论？</li>
</ul>
</li>
<li>在提纲的高级版本中，还应包括实验部分的所有小节（达到段落副标题的级别），并指明哪些信息将放入补充材料（Microfilm section）。</li>
</ul>
</li>
<li><strong>结果与讨论 (Results and Discussion)</strong>
<ul>
<li>结果和讨论通常合并在一起。</li>
<li>本节应按主要主题组织。各部分应使用<strong>粗体副标题</strong>，以使结构清晰，并帮助读者浏览最终文本以找到感兴趣的部分。</li>
<li>以下列表包含了一些可以作为章节标题的示例短语：
<pre><code>-   Synthesis of Alkane Thiols (烷基硫醇的合成)
-   Characterization of Monolayers (单分子层的表征)
-   Absolute Configuration of the Vicinal Diol Unit (邻二醇单元的绝对构型)
-   Hysteresis Correlates with Roughness of the Surface (滞后现象与表面粗糙度相关)
-   Dependence of the Rate Constant on Temperature (速率常数对温度的依赖性)
-   The Rate of Self-Exchange Decreases with the Polarity of the Solvent (自交换速率随溶剂极性降低)
</code></pre>
</li>
<li>尽量使这些章节标题具体且信息丰富。例如，“自交换速率随溶剂极性降低”显然比“速率测量”长，但对读者更有用。</li>
<li>通常，尝试涵盖主要的共同要点：
<ul>
<li>起始材料的合成</li>
<li>产物的表征</li>
<li>表征方法</li>
<li>测量方法</li>
<li>结果（速率常数、接触角等任何测量值）</li>
</ul>
</li>
<li>在提纲中，不要写大量文本，但要把所有数据放在正确的位置：任何文本只需说明该部分将包含什么内容。</li>
<li>应包含：
<ul>
<li>章节标题 (Section Headings)</li>
<li>图 (Figures) (带图注)</li>
<li>反应路线/示意图 (Schemes) (带图注和脚注)</li>
<li>方程式 (Equations)</li>
<li>表格 (Tables) (格式正确)</li>
</ul>
</li>
<li>记住，把一篇论文看作是实验结果的集合，通过图、表、方程式和反应路线（schemes）尽可能清晰、经济地进行总结。论文中的文本仅用于解释数据，是次要的。信息越能压缩到表格、方程式等中，论文就越短、越易读。</li>
</ul>
</li>
<li><strong>结论 (Conclusions)</strong>
<ul>
<li>在提纲中，用简短的短语或句子列表总结论文的结论。</li>
<li>不要重复结果部分的内容，除非需要特别强调。</li>
<li>结论部分就应该是结论，而不是总结。它应该增加一个新的、更高层次的分析，并明确指出工作的意义。</li>
</ul>
</li>
<li><strong>实验部分 (Experimental)</strong>
<ul>
<li>按照与结果部分相对应的正确顺序，包含实验部分的所有段落副标题。</li>
</ul>
</li>
</ol>
<h2><strong>2.4. 总结</strong></h2>
<ul>
<li>在一个项目的早期就开始撰写可能的论文提纲。不要等到“结束”。结束可能永远不会到来。</li>
<li>围绕易于理解的数据——表格、方程式、图、反应路线（schemes）——来组织提纲和论文，而不是围绕文本。</li>
<li>按重要性排序，而不是按时间顺序。撰写论文的一个重要细节涉及主题的权重。新手通常按时间顺序组织论文：即，他们叙述其实验过程，从他们珍视的最初失败开始，到高潮的成功结局结束。这种方法完全错误。<strong>从最重要的结果开始，将次要结果放在后面，或者干脆省略。</strong> 读者通常不关心你是如何得到重大结果的，只关心结果是什么。</li>
<li>短论文比长论文更容易阅读。</li>
</ul>
<h1><strong>3. 一些写作风格要点</strong></h1>
<ul>
<li>
<p><strong>不要使用名词作形容词：</strong></p>
<ul>
<li>不应：
<pre><code>ATP formation; reaction product
</code></pre>
</li>
<li>应：
<pre><code>formation of ATP; product of the reaction
(ATP的形成；反应的产物)
</code></pre>
</li>
</ul>
</li>
<li>
<p><strong>单词“this”后面必须跟一个名词，使其指代明确。</strong></p>
<ul>
<li>不应：
<pre><code>This is a fast reaction; This leads us to conclude
</code></pre>
</li>
<li>应：
<pre><code>This reaction is fast; This observation leads us to conclude
(这个反应很快；这个观察使我们得出结论)
</code></pre>
</li>
</ul>
</li>
<li>
<p><strong>统一使用过去时描述实验结果。</strong></p>
<ul>
<li>不应：
<pre><code>Addition of water gives product.
</code></pre>
</li>
<li>应：
<pre><code>Addition of water gave product.
(加入水得到了产物。)
</code></pre>
</li>
</ul>
</li>
<li>
<p><strong>尽可能使用主动语态。</strong></p>
<ul>
<li>不应：
<pre><code>It was observed that the solution turned red.
</code></pre>
</li>
<li>应：
<pre><code>The solution turned red.
或者
We observed that the solution turned red.
(溶液变红了。或者 我们观察到溶液变红了。)
</code></pre>
</li>
</ul>
</li>
<li>
<p><strong>完成所有的比较。</strong></p>
<ul>
<li>不应：
<pre><code>The yield was higher using bromine.
</code></pre>
</li>
<li>应：
<pre><code>The yield was higher using bromine than chlorine.
(使用溴的产率比使用氯的产率高。)
</code></pre>
</li>
</ul>
</li>
<li>
<p><strong>所有论文字稿使用双倍行距（不是单倍或1.5倍行距），冒号后和句子末尾的句号后留两个空格。页边距要足够宽。</strong></p>
</li>
<li>
<p><strong>假设我们所有的论文都将使用美国化学会（American Chemical Society, ACS）的风格。你可以从三个来源很好地了解这种风格：</strong></p>
<ol>
<li><strong>期刊。</strong> 只需查看期刊上的文章，模仿你看到的组织结构。</li>
<li><strong>研究组以前的论文。</strong> 通过查看以前的论文，你可以确切地看到一篇论文应该“看起来”是什么样子。如果你写的东西看起来不同，那可能就不是我们想要的。</li>
<li><strong>《ACS作者手册》(The ACS Handbook for Authors)。</strong> 有用、详细，尤其是关于参考文献的部分，第173-229页。</li>
</ol>
</li>
<li>
<p><strong>我还建议你阅读 Strunk 和 White 的《风格要素》(The Elements of Style, Macmillan: New York, 1979, 3rd ed.) 来培养语感。</strong> 研究组图书馆里还有一些关于科学写作的其他书籍；这些书都包含有用的建议，但读起来并不生动。也有几本关于图表设计的优秀书籍。</p>
</li>
</ul>
