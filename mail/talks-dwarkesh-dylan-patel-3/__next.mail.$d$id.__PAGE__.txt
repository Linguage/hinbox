<h2>访谈正文</h2>
<p>再次和我的双胞胎兄弟 Dylan Patel 聊天，非常开心。</p>
<p>我们梳理了未来几年的实验室经济学——随着 RSI 临近，从推理向训练的转变；以及 Anthropic 和 OpenAI 如何有望在未来几年内控制世界上大部分可用 FLOPs（因为它们能更好地将算力变现，从而在竞价中胜过所有人）。</p>
<p>然后我们讨论了，到本十年末我们将看到的超过 $10T 的 AI 总资本支出，是否会引发一场主权债务危机——超大规模企业的债务推高利率，把没有 AI 敞口国家推向破产，并让非 AI 类股票崩盘。</p>
<p>有一个我们没能解决的问题是：是否存在任何东西，能够对抗这个行业中所有冲向中心化的力量——训练中的规模经济、算力的稀缺，以及最终的持续学习和 RSI。</p>

<h2>文字记录</h2>
<h3>两家实验室很快将控制世界上大部分算力</h3>
<p><strong>Dwarkesh Patel:</strong></p>
<p>好，我回来了，和我一起的是 <a href="https://semianalysis.com/">SemiAnalysis</a> 创始人 Dylan Patel。我们版本的家庭感恩节晚餐，就是每年一次的播客。但我们其实没有血缘关系。</p>
<p><strong>Dylan Patel:</strong></p>
<p>别把这事告诉大家。</p>
<p><strong>Dwarkesh Patel:</strong></p>
<p>这会毁掉那个神话。基本上，世界经济走向越来越取决于实验室经济走向、算力市场走向等等。我想理解这个疯狂的未来在几年内会落到哪里。但让我们先从今天所处的位置开始。给我讲讲现在的实验室算力和实验室收入，也许再往外推一两年。</p>
<p><strong>Dylan Patel:</strong></p>
<p>回到去年，甚至到去年年底，<a href="https://fortune.com/2025/10/07/data-centers-gdp-growth-zero-first-half-2025-jason-furman-harvard-economist/">美国 GDP 增长的大部分都只是 AI 基础设施</a>。展望今年，上线算力中大约三分之一是给实验室的，给 OpenAI 和 Anthropic 的。它可能由别人建设，然后租给它们，但最终客户是它们。</p>
<p>随着我们走向未来，<a href="https://epoch.ai/data-insights/hyperscaler-capex-trend">算力的数字正在膨胀</a>。今年我们的 <a href="https://www.investopedia.com/terms/c/capitalexpenditure.asp">CapEx</a> 略高于 1 万亿美元。到 28 年，将超过 $2 万亿。实验室在其中所占的比例也在不断增加。所以最终，你会看到一个非常有趣的情况：实验室正从每年花费数百亿美元的公司，变成每年花费数千亿美元的公司，并预测到本十年末甚至每年花费数万亿美元。这至少是它们已经开始与合作伙伴签署的一些合同。</p>
<p>这要求它们的经济结构发生重大重塑。到目前为止，它们一直主要是亏损的公司。Anthropic 在 Q2 开始盈利。据信在 Q3 的某个时候，随着 <a href="https://openai.com/index/introducing-the-codex-app/">Codex</a> 和 <a href="https://openai.com/index/previewing-gpt-5-6-sol/">5.6</a> 等的更大崛起，OpenAI 甚至也可能开始盈利。但如果我们回到一年前，它们所有的钱都是风险投资资助的亏损。如果我们回到甚至今年年初，那也是风险投资资助的亏损。它们现在已经转危为安，实际上开始盈利了。</p>
<p>这并不意味着它们不再吸收新资本。新资本仍在流入，以进一步加速增长。但最终，它们越来越多的业务是由自身收入支撑，而不是靠注入它们的资本。在过去一年半里，它们的利润率确实飙升了。算力的基础成本往往约为<a href="https://www.nrc.gov/docs/ML1209/ML120960701.pdf">每兆瓦</a>1000万、1300万或1500万美元。</p>
<p>现在发生的事情最有趣的方面是：以前，如果它们服务一个模型——<a href="https://openai.com/index/gpt-4-research/">GPT-4</a> 在 <a href="https://en.wikipedia.org/wiki/Nvidia">Nvidia</a> <a href="https://en.wikipedia.org/wiki/Hopper_%28microarchitecture%29">Hopper</a> <a href="https://en.wikipedia.org/wiki/Graphics_processing_unit">GPUs</a> 上提供服务——这对 OpenAI 来说产生的是负的<a href="https://www.investopedia.com/terms/g/grossmargin.asp">毛利率</a>。但现在，当 OpenAI 服务 GPT-5.6，或 Anthropic 服务 <a href="https://www.anthropic.com/news/claude-opus-5">Opus 5</a> 或 <a href="https://www.anthropic.com/claude/fable">Fable 5</a> 时，它们的收入创造已经远远超过了每兆瓦增量1000-1500万美元。就 Anthropic 而言，收入已经高达每兆瓦 $50 million。这现在使它们能够做到的是：“嘿，如果我在<a href="https://cloud.google.com/discover/what-is-ai-inference">推理</a>容量上花 10 美元，我实际上能产生 50 美元的收入，然后我可以回过头来，把所有这部分利润增量地花在训练上。”</p>
<p><strong>Dwarkesh Patel:</strong></p>
<p>我非常想理解的一件事是，你如何看待算力在实验室层面的中心化，或者说流向世界的算力与流向实验室的算力之间的相对比例。如果你说现在边际算力的三分之一流向实验室，那么到什么时候，世界上超过一半的增量算力会流向实验室？到什么时候，实验室基本上会拥有世界上绝大部分算力？</p>
<p><strong>Dylan Patel:</strong></p>
<p>今年年初，OpenAI 从 2 吉瓦起步，Anthropic 不到 2 吉瓦。到今年年底，它们都超过 5 吉瓦。所以它们整体算力变为原来的3-4倍。当你看到新增的增量算力时，这大约占今年新增算力的 30%。</p>
<p>随着我们迈入明年，鉴于已经签署、敲定和落笔的内容，你会看到更加戏剧性的情况。Anthropic 和 OpenAI 明年将拿走多达 40% 到 50% 的算力。这种中心化看起来并没有放缓或停止。事实上，它看起来只是在加速。</p>
<p>为它们建设这些算力的人会发生变化。明年，一个重要的新进入者例如是 <a href="https://en.wikipedia.org/wiki/SpaceX">SpaceX</a>，它正在建设大量算力。它们正积极地将相当一部分<a href="https://www.wsj.com/livecoverage/stock-market-today-dow-sp-500-nasdaq-05-20-2026/card/anthropic-rents-1-25-billion-of-spacex-data-center-capacity-each-month-uNS0TiOKvaa8wo4GhxII">租给 Anthropic</a>，很可能也租给 OpenAI，因为它们是那些有边际能力支付最高价格的一方。此外，OpenAI 和 Anthropic 也开始建设自己的算力——<a href="https://www.wsj.com/tech/ai/openai-broadcom-develop-custom-chip-for-ai-inference-beafd74a">OpenAI 用自己的芯片</a>，<a href="https://www.anthropic.com/news/google-broadcom-partnership-compute">Anthropic 用从 Google 购买的 TPU</a>，并<a href="https://www.anthropic.com/news/anthropic-invests-50-billion-in-american-ai-infrastructure">与 Fluidstack 一起部署</a>。</p>
<p>所以你问：“嘿，什么时候世界上新增算力的一半会只流向 OpenAI 和 Anthropic？”实际上到明年年底，增量算力的一半就已经流向 Anthropic 和 OpenAI 了。</p>
<p><strong>Dwarkesh Patel:</strong></p>
<p>因为算力增长如此之快，增量算力基本上将构成大部分算力。所以这非常快——你是说也许在一年半或两年内——世界上大部分算力将由两家实验室拥有，或者至少是在服务来自两家实验室的需求。</p>
<p>有这样一个趋势：也许世界算力以吉瓦计每年翻一番，但前沿实验室的算力每年翻三倍。如果你保持当前趋势，它会从今年年初的 2 增长到今年年底接近 6。就是乘以 3。到 2027 年底是 18，到 2028 年底是 54。你是不是觉得：“好吧，到那时，考虑到世界算力总量，它们根本不可能继续翻三倍”？你如何看待未来几年的世界算力状况？</p>
<p><strong>Dylan Patel:</strong></p>
<p>如果今年增量算力增加 30 吉瓦，明年 50 吉瓦，后年大约 70 吉瓦，你最终会看到这个非常有趣的现象。今年部署的每一瓦，都比两年前部署的瓦效率高得多。世界上算力的巨大比例是今年部署的。尽管它没有让部署的瓦数翻倍，但我部署的是 <a href="https://newsletter.semianalysis.com/p/nvidias-christmas-present-gb300-b300-reasoning-inference-amazon-memory-supply-chain">GB300s</a>、<a href="https://newsletter.semianalysis.com/p/tpuv7-google-takes-a-swing-at-the">TPUv7s</a> 和 <a href="https://newsletter.semianalysis.com/p/aws-trainium3-deep-dive-a-potential">Trainium3s</a>，它们要高效得多得多得多。它们的每瓦性能比上一代芯片高 3-5 倍。</p>
<p>所以最终你在这里有一个巨大的阶梯。如果 Anthropic 和 OpenAI 明年拿走 45% 的算力，那么可以说到 27 年 12 月，它们已经拿走了世界上新增增量算力的一半。但那一半世界新增增量算力，实际上性能高于此前所有算力。所以你在那之上又有一个乘数。到 2028 年底左右——如果这个趋势继续下去，而我看不到任何阻止它的东西——它们将独自控制世界上大部分可用 <a href="https://en.wikipedia.org/wiki/Floating_point_operations_per_second">flops</a>。</p>
<h3>$6 billion 的晶圆厂资本支出支撑 $1t+ 的终端收入</h3>
<p><strong>Dwarkesh Patel:</strong></p>
<p>我困惑的是，如果我们进入一个算力价值增长如此之大的世界，你为什么认为 2028 年我们只会增加 80 吉瓦？</p>
<p><strong>Dylan Patel:</strong></p>
<p>顺便说一句，这是上限。这就是那种，“我他妈看多到爆”的情况。</p>

<p><strong>Dylan Patel:</strong></p>
<p>我要调侃你一下，但你说 wafers 的方式太他妈印度了。Vafers。</p>
<p><strong>Dwarkesh Patel:</strong></p>

<p><strong>Dwarkesh Patel:</strong></p>

<p><strong>Dylan Patel:</strong></p>

<p>能给我来点“wedgies”吗？</p>
<p>总之，这是针对一吉瓦的。我让一个大语言模型运行了你的晶圆厂设备模型，算出了基本上每年生产一吉瓦算力所需的工具成本。它说是30到40亿美元。现在假设你再加上<a href="https://en.wikipedia.org/wiki/Cleanroom">洁净室</a>、厂房外壳以及<a href="https://en.wikipedia.org/wiki/Semiconductor_fabrication_plant">晶圆厂</a>里的其他所有东西。那么60亿美元的晶圆厂资本支出每年就能产出一吉瓦。一吉瓦目前能产生1000亿美元的收入。</p>
<p>但同样，这 60 亿美元的资本支出每年生产一吉瓦，而那一吉瓦每年产生 1000 亿美元。所以在五年的时间里，第一吉瓦已经产生了五年的利润，晶圆厂生产的第二吉瓦产生了四年的利润，以此类推。晶圆厂层面 60 亿美元的资本支出将产生超过一万亿美元的最终 AI 收入。</p>
<p><strong>Dylan Patel:</strong></p>
<p>是的。这一路上有很多运营支出。还有很多其他资本支出，比如数据中心、电力。</p>
<p><strong>Dwarkesh Patel:</strong></p>
<p>而且你还得为研发向 OpenAI 付钱。</p>
<p><strong>Dylan Patel:</strong></p>
<p>安装。这里有很多不同的人都需要钱。</p>
<p><strong>Dwarkesh Patel:</strong></p>
<p>把其中一半扣给所有这些中间商。这仍然意味着晶圆厂资本支出和最终产生的收入之间存在 100 倍的差距。实际上还不止，但我们只是非常保守。结果……这就是资本主义。你有这个巨大的差距，你可以把 1 美元变成 100 美元。他们不会想办法造更多<a href="https://www.zeiss.com/semiconductor-manufacturing-technology/smt-magazine/so-does-euv-lithography-work.html">镜子</a>吗？</p>
<p><strong>Dylan Patel:</strong></p>
<p>他们会的。只是这些镜子需要一些时间来制造。</p>
<p><strong>Dwarkesh Patel:</strong></p>
<p>但紧急情况太大了，Anthropic 和 OpenAI 会说，“我们现在就能赚一万亿美元，但我们只是卡在 <a href="https://en.wikipedia.org/wiki/ASML_Holding">ASML</a> 机器所用的镜子上。”如果我们为此花 1000 亿美元，怎么能造更多镜子？这就是我们很快会陷入的局面。我们无法解决那个供应约束？这真的很难想象。</p>
<p><strong>Dylan Patel:</strong></p>
<p>你已经看到人们在这里做有趣的套利，他们买<a href="https://en.wikipedia.org/wiki/Gas_turbine">涡轮机</a>然后试图转售，因为涡轮机的价值要高得多，因为它是卡住你数据中心的瓶颈。我认为如果有人有 4 亿美元并且有能力说服 ASML 卖给他们一台 <a href="https://en.wikipedia.org/wiki/Extreme_ultraviolet_lithography">EUV</a> 工具，他们完全应该去买一台，等着，然后以超过十亿美元的价格卖掉。</p>
<p>但最终，是的，资本主义会导致这些东西扩张。但这是一条鞭子。鞭子信号传到尾端需要很长时间。供应链不会立即反应。事实上，你去和 <a href="https://en.wikipedia.org/wiki/Carl_Zeiss_SMT">Carl Zeiss</a> 的人谈谈，他们会说，“对对对，我们需要在这个十年末之前制造 100 台 EUV 工具。”今年早些时候我们做那期节目时，他们甚至不认为需要制造那么多，足够每年制造 100 台 EUV 工具的镜子。现在他们说，“好吧，我们需要这么做。”但实际上，由于正在发生的所有经济因素，应该还要更多。这需要很长时间。</p>

<p><strong>Dylan Patel:</strong></p>
<p>我不认为他们会那样做，但是……</p>

<h3>如果实验室出价高于所有人，算力价格将上涨</h3>
<p><strong>Dwarkesh Patel:</strong></p>
<p>我真正想理解的关键问题是：如果当前趋势继续，到 2028 年底每个实验室将超过 50 吉瓦。所以它们之间将有 100 吉瓦。正如你所说，由于硬件变得更好，这些吉瓦到 2028 年将驱动比现在多许多倍的吞吐量或性能。不仅每瓦浮点运算次数增加了，而且硬件在处理 AI 工作负载方面也变得更好了。</p>
<p>好，那么到 2028 年底实验室有 100 吉瓦。世界算力是多少？</p>
<p><strong>Dylan Patel:</strong></p>
<p>我认为这可能有点困难，因为到 2028 年他们已经拿走了 70-80% 的增量算力。我不确定那时市场会发生什么。算力价格要飙升多少，他们才能真正买到 70-80% 的算力？Google 或 Meta 或 Amazon 愿意卖那么多吗？</p>
